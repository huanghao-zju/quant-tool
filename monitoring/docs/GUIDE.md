# 监控系统速读手册

> 5 分钟看懂这套系统在盯什么、为什么盯、消息怎么读。
> 详细规格见 `SPEC.md`；本文只讲"人话版"。

---

## 一、它在防什么：一个两段式剧本

这套系统押注的危机剧本只有一个（2026-07 宏观分析的结论）：

```
第一段（Mode B）：日元贬值失控
  日本财政扩张/通胀 → 日元跌、日本国债(JGB)利率飙
  → USDJPY 冲向 165+、30Y JGB 创新高
       ↓ 政策被逼到墙角
第二段（Mode A）：政策被迫转向 → 套息平仓
  日本央行被迫加息 / 财务省大规模干预 → 日元急升
  → 全球借日元买美股的钱（套息交易）被迫回补
  → 卖美股还日元 → 日经+纳指同跌 → 全球传导
```

**2024 年 8 月 5 日的全球崩盘就是这个剧本**：USDJPY 从 161 两周急跌 10 円，
日经单日 -12%。本系统的回测验收就是"必须在那次崩盘前给出提前量"。

**2026 年 8 月我们又经历了一次半场版**：美日联手干预 → USDJPY 一周急跌
6.2 円（→橙色）→ 空头一周平掉 72%（→触发红色，后修正为橙色，因为这次
是有序平仓、没有传导）。这次实战验证了系统能抓住信号，也暴露并修复了
"有序干预 vs 失控级联"的区分问题。

## 二、两条独立轨道（最容易混淆的点）

| | 轨道① 阶段状态机 | 轨道② 慢变量看板 n/9 |
|---|---|---|
| 盯什么 | **日元通道**（剧本主线） | **全局信用/宏观**（外围环境） |
| 性质 | 快，速度型信号为主 | 慢，水平型阈值 |
| 输出 | 绿→黄→橙→红 | 命中个数 0~9 |
| 关系 | **互不联动**（唯一例外：HY OAS>400bp 直接跳红） | |

**为什么会出现"红色告警但看板 1/9"**：日元通道先动、全局面后动是正常的
领先-滞后关系。系统的价值恰恰是在看板还平静时给你提前量；等看板分也上来，
说明已经传导成全局事件了。

## 三、阶段状态机：每一级的含义和触发条件

**🟢 绿色（基线）**：啥事没有。只有周六周报 + 工作日平安报。

**🟡 黄色 = "第一段剧本开演"（贬值失控）**，任一触发：
- USDJPY ≥165 连续两天收盘（贬值确认线）
- 30Y JGB 创历史新高 且 10Y >2.3%（国债市场失控）
- 10Y/30Y JGB 单周飙 +15bp（利率失控的速度印记）
- 人工录入：财政包超预期 / JGB 拍卖疲软

**🟠 橙色 = "政策被迫转向"（剧本转折点）**，任一触发：
- USDJPY 从 30 日高点单周急跌 >5 円（干预/转向的市场印记）
- CFTC 日元净空头两周骤减 >30%（平仓开始）
- 人工录入：BOJ 会议间行动 / MOF 无预告干预

**🔴 红色 = "套息平仓 + 全球传导"（第二段全面展开）**，任一触发：
- USDJPY 两周急跌 >10 円 **且**（VIX 单日跳升 / 日经+纳指同日崩）
- CFTC 净空头两周骤减 >50% **且**（VIX 跳升 / 股市崩 / 日元仍在加速升值）
  ——后半个"且"是 2026-08 实战后加的：区分失控级联 vs 有序干预平仓
- HY OAS 突破 400bp（全局信用崩，任何阶段直接跳红）

**降级**：连续 10 个交易日无当前阶段条件 → 自动降一级（会推送）。
降级慢是刻意的——防止状态反复横跳。

## 四、每个指标一句话（收到消息时对照看）

### 日元通道（决定阶段颜色）
| 指标 | 一句话 | 危险方向 |
|---|---|---|
| USDJPY | 剧本主角。**数值跌=日元升值=危险**（平仓方向） | 快速下跌 |
| 10Y/30Y JGB | 日本国债利率。飙升=财政失控/政策被逼 | 快速上行 |
| CFTC 日元净头寸 | 投机盘押注日元跌的规模。极端拥挤后骤减=踩踏平仓 | 空头骤减 |
| 日经225 | 传导确认：套息平仓先砸日股 | 单日大跌 |

### 慢变量看板 9 项（外围环境体检表）
| 指标 | 一句话 | 阈值 |
|---|---|---|
| HY OAS | 美国垃圾债利差=全局信用体温计 | ≥350 预警 / >400 跳红 |
| VIX | 美股恐慌指数 | >25 或单日+8 |
| SOFR−IORB | 美元钱荒探测器（利差转正走阔=回购压力） | 连续5日 |

| 布伦特油价 | 地缘/日本贸易条件 | >95 美元 |

## 五、你会收到的 5 种消息

| 消息 | 频率 | 你该做什么 |
|---|---|---|
| **[阶段迁移]** | 出事才发 | 看"➤ 你的既定动作"那一行，照做（actions.yaml 里你自己写的） |
| **[周报]** | 每周六早7点 | 扫一眼全部现值和看板分 |
| **[平安报]** | 工作日早间 | 确认系统活着；**哪天没收到=系统可能挂了，要查** |
| **[看板分变动]** | 偶发 | 外围环境变化，留意但不必行动 |
| **[数据源故障]** | 偶发（只报新坏的） | 连坏3天的源，有空看下 Actions 日志 |

## 六、系统不会替你做的事（人工职责清单）

1. **事件录入**（`config/events.yaml`）：BOJ 会议间行动、MOF 干预、财政包、
   JGB 拍卖疲软——这些自动化不了，看到新闻后手工记一行，状态机会读入。
2. **日历提醒**（`config/calendar.yaml`）：JGB 拍卖日、云厂商财报日，
   提前填日期，系统到期提醒你去关注结果。
3. **季度重标定**：所有阈值基于 2026-07-04 市场状态标定（USDJPY≈162）。
   **每季度必须人工复核一次**——市场中枢移动后，165 这类绝对水平线会失效。
   下次复核：2026-10 初。
4. **红色≠自动全清仓**：工具是提醒器不是决策者。红色告警附上你的既定动作，
   但执行前快速交叉验证（USDJPY 是否仍在加速、VIX 是否跳升）——2026-08
   的经验：有序干预平仓也可能触发强信号。
